# stadium — Pokémon Stadium as a 3D Game-Engine Kit

`pokestadium` (the pret decomp of Pokémon Stadium N64) repurposed as
building blocks for 3D games in other genres — see `AGENTS.md` for
architecture, conventions, and dev workflow.

AGENTS.md is the single source of truth for this repo. Update it, not
this file, when the project changes.
